# IM1003 - Object Oriented Programming: Sudoku Game

## Overview
This project was developed as part of IM1003 - Object Oriented Programming. It is a Sudoku game built in Java with various interactive features.

## Features
- **Interactive UI**: Includes a welcome screen, light and dark mode.
- **In-Game Music**: Enhances user experience with background music.
- **Number Highlighter**: Highlights selected numbers for easier tracking.
- **Three Difficulty Levels**: Sudoku boards are generated with different difficulty levels using a designed algorithm.

## Technologies Used
- Java
- Object-Oriented Programming

## How to Run
1. Clone this repository:
   ```sh
   git clone https://github.com/yourusername/SudokuGame.git
   ```
2. Navigate to the project directory:
   ```sh
   cd SudokuGame
   ```
3. Compile and run the program:
   ```sh
   javac SudokuMain.java
   java SudokuMain
   ```
